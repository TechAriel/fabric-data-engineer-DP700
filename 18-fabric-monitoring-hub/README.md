# Monitoring Fabric Activity with the Monitoring Hub

This project demonstrates how to monitor **data engineering activities in Microsoft Fabric** using the Monitoring Hub.

The lab focuses on tracking execution, analysing run history, and customising monitoring views for better observability.

---

## Architecture

Dataflow (Ingestion)  
        ↓            
Lakehouse Table  
        ↓                
Spark Notebook (Processing)  
        ↓                  
Monitoring Hub (Tracking & Insights)  

---

## Technologies Used

- Microsoft Fabric
- Lakehouse
- Dataflow Gen2
- Spark Notebooks
- Monitoring Hub

---

## Key Concepts Demonstrated

### Activity Monitoring

- Track running and completed jobs
- Monitor Dataflows and Notebooks

---

### Run History Analysis

- View historical executions
- Drill into run details

---

### Observability

- Understand pipeline behavior
- Identify failures or delays

---

### Monitoring Customization

- Apply filters (status, type)
- Customize columns for insights
